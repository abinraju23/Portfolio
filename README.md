# Abin Raju Portfolio

Personal portfolio website of Abin Raju, an MSc Data Analytics student in Dublin focused on data analytics, ETL pipelines, dashboards, SQL, Python, and machine learning.

## Live Website
[View Portfolio](https://abinraju23.github.io/Portfolio/Last)

## About
This portfolio showcases my background, technical skills, projects, education, and contact information in a modern responsive website.

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Features
- Responsive portfolio layout
- Projects section
- Experience and education sections
- Contact section
- Interactive visual styling and animations

## Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/abinraju23/Portfolio.git
   ```
2. Open the project folder.
3. Run the `index.html` file in your browser.
